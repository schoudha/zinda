Product Requirements Document (PRD)
1. App Overview

Name: Zinda  Description: A "local-first" Progressive Web App (PWA) that tracks daily, weekly, monthly, and yearly goals. It uses an LLM-first engine to parse natural language goals into actionable steps and provides custom progress visualization (e.g., charts for finance, checklists for health).  Target Audience: Individuals seeking self-improvement and goal tracking with spiritual motivation. Core Philosophy: "Simple, Mobile-First, LLM-Powered." 

2. Tech Stack (Strict Constraints)
Frontend: Next.js 15 (App Router), React, TypeScript, Tailwind CSS.

UI Library: shadcn/ui (Cards, ScrollArea, Charts for financial goals).


PWA: @ducanh2912/next-pwa (Must function natively on iOS/Android). 


AI/LLM: Google Gemini 3 Flash (via AI SDK) for goal breakdown and analysis. 

Backend/DB: Supabase (PostgreSQL, Auth, Edge Functions for cron jobs).

State Management: Zustand (local state) + TanStack Query.

Notifications: Web Push API (Service Workers) + Supabase Edge Functions.

3. Core Features & User Flows
Feature A: Home Page (Dashboard)

Header: Displays a randomized motivational quote from the Quran. 

Main View:

A scrollable list of "Goal Cards." 


Zero State: If no goals exist, show a prominent "Create your first goal" card. 

Goal Card UI: Summary of progress (e.g., "3/5 tasks done today").

Feature B: AI Goal Creation
Flow:

User types a goal in natural language (e.g., "I want to save $5000 this year" or "Get fit"). 


LLM Action: Send prompt to Gemini 3 Flash. 

Response: Gemini returns structured JSON:

Goal Type (Financial, Health, Skill).

Actionable steps broken down by frequency (Daily, Weekly, Monthly, Yearly). 

User reviews and confirms -> Save to DB.

Feature C: Custom Progress Trackers
Logic: The UI adapts based on the "Goal Type" determined by Gemini.


Financial: Render a Line/Bar chart (using Recharts/shadcn charts) tracking spend/saving. 


Health/Habit: Render a habit grid or streak counter. 

Feature D: Intelligent Notifications
Trigger: Time-based cron jobs via Supabase Edge Functions.

Schedule:


Morning Brief: A quick rundown of daily tasks. 


Evening Check-in: Progress log prompt. 

Delivery: System Push Notification.

4. Data Model (Schema Design)
Table: profiles
id (uuid, PK)

timezone (text, for notification scheduling)

Table: goals
id (uuid, PK)

user_id (fk)

title (text)

description (text)

category (enum: 'financial', 'health', 'learning', 'other')

metadata (jsonb, stores specific target numbers, e.g., { target_amount: 5000 })

Table: milestones
id (uuid, PK)

goal_id (fk)

periodicity (enum: 'daily', 'weekly', 'monthly', 'yearly')

title (text, generated by AI)

is_completed (boolean)

due_date (date)

6. Design System & UI Rules

Platform: Mobile-first design (views must be optimized for touch, hidden scrollbars). 

Theme: Clean, minimal, spiritually grounding.

Typography: Legible sans-serif for UI, serif for Quran quotes.

7. Implementation Plan (Step-by-Step)
Phase 1: Foundation: Setup Next.js PWA with Supabase Auth and Tailwind.

Phase 2: Dashboard: Build the Home Page with the Quran quote API and empty state.

Phase 3: The AI Engine: Implement Gemini 3 Flash API to parse text -> JSON structure for goals.

Phase 4: Dynamic UI: Build the "Financial" vs "Health" card variants.

Phase 5: Notifications: Configure Web Push and schedule the Morning/Evening cron jobs.
